# Miniaturas de productos · Control de peso

Serie cuadrada para promoción en WhatsApp e Instagram.

- Green Tea: `PUEDE APOYAR LA TERMOGÉNESIS Y LA OXIDACIÓN DE GRASA`
- Carnilis: `APOYA EL CONTROL DE ANTOJOS Y EL USO DE GRASA COMO ENERGÍA`
- Galphimia: `PUEDE AYUDAR A BAJAR EL GATILLO DE COMER POR ANSIEDAD`
- Fat-Less: `APOYO DIGESTIVO Y HEPÁTICO · AYUDA A PROCESAR LAS GRASAS`

Texto común:

- `KIT CONTROL DE PESO`
- `PREGUNTA POR WHATSAPP`

Las piezas explican la función de apoyo de cada producto sin prometer
resultados garantizados. Evitan indicaciones de dosis y aclaran las
limitaciones relevantes: el té verde tiene resultados variables, Galphimia no
sustituye atención profesional y Fat-Less no se presenta como quemador de
grasa.
